# WSL

<details><summary>WSL Installation</summary>

| Description | Command / Action |
|-------------|------------------|
| Check available Linux distros | `wsl --list --online` |
| Install a distro of your choice | `wsl --install -d <distro-name>` |
| Update WSL to latest version | `wsl --update` |
| Check the version | `wsl --version` |
|  | `wsl.exe --status` |
| Enable required Windows features | Go to **Search Windows features on or off** → Enable **Windows Subsystem for Linux** and **Virtual Machine Platform** |

</details>
